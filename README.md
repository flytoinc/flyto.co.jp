# flyto.co.jp

株式会社フライト（FLYTO Inc.）のコーポレートサイト。

## 技術構成

- Vanilla HTML / CSS / JavaScript
- Google Fonts (Inter + Noto Sans JP)
- レスポンシブ対応

## ローカル開発

```bash
npx serve .
```

## デプロイ

Cloudflare Pages で GitHub 連携自動デプロイ。
`main` ブランチに push すると自動で反映されます。

## ページ構成

| ページ | ファイル | 内容 |
|--------|----------|------|
| Top | `index.html` | ヒーロー・サービス紹介・会社概要 |
| About | `about.html` | 企業理念・会社情報 |
| Service | `service.html` | 3事業の詳細紹介 |
| Contact | `contact.html` | お問い合わせフォーム |
