プライバシーポリシー

株式会社フライト（以下「当社」）は、事業を通じて取り扱う個人情報を、個人情報の保護に関する法律その他の法令に従い、以下のとおり適切に取り扱います。

1. 取得する情報

当社は、お問い合わせ、商品のご購入、店舗・スペースのご予約などに際して、氏名、連絡先（メールアドレス・電話番号）、配送先住所、お問い合わせ内容など、必要な範囲の情報を取得します。

2. 利用目的

  • お問い合わせへの回答、ご予約・ご注文の受付と履行、商品の配送
  • アフターサービス、返品・返金等のご対応
  • サービスの改善および新サービスのご案内
  • 法令に基づく対応

3. 第三者への提供

当社は、ご本人の同意がある場合、法令に基づく場合、または利用目的の達成に必要な範囲で業務を委託する場合（配送業者・決済事業者など）を除き、個人情報を第三者に提供しません。

4. 社内業務ツールによる Google ユーザーデータの取り扱い

当社は、当社が管理するメールアカウントに届いたお問い合わせや注文の連絡を見落とさないよう、社内向けの業務ツール「mail-task-agent」を運用しています。このツールは Google API を通じて当社自身の Gmail アカウントにアクセスします。当社以外の方がこのツールを利用したり、Google アカウントを連携したりすることはありません。

  • アクセスする情報：当社の Gmail アカウントに届いたメールの送信者、件名、日時、本文（読み取り専用の権限 gmail.readonly のみを使用します）。
  • 利用目的：対応が必要なメールを判別し、当社の社内チャット（Slack）に「やること」として通知するためにのみ利用します。メールの送信・削除・変更は行いません。
  • 保存：同じメールを重複して通知しないよう、送信者・件名・日時・判定結果を当社のデータベースに保存します。メール本文は保存しません。
  • 共有：対応の要否を判定するため、メールの内容を AI サービス（Anthropic 社の Claude API）に送信することがあります。また、通知内容（送信者・件名・やること）は当社の Slack ワークスペースに投稿されます。これら以外の第三者に提供・販売することはありません。広告目的には一切利用しません。
  • 人による閲覧：通知内容は当社の担当者のみが閲覧します。
  • 削除：当社は Google アカウントの設定画面からいつでもこのツールのアクセス権を取り消すことができ、取り消した場合はそれ以降メールにアクセスしません。保存したデータの削除をご希望の方は、下記の窓口までご連絡ください。

mail-task-agent が Google API から受け取った情報の利用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

5. 安全管理

当社は、取り扱う情報の漏えい、滅失または毀損を防ぐため、アクセス権限の管理など必要かつ適切な安全管理措置を講じます。

6. 開示・訂正・削除のご請求

ご本人から個人情報の開示、訂正、利用停止または削除のご請求があった場合は、ご本人であることを確認のうえ、法令に従い速やかに対応します。
